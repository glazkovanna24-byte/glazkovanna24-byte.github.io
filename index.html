Level UP Rclone

Personal-use backup tool

Level UP Rclone is a private, owner-operated utility that uses Rclone and the Google Drive API to back up archives of game mods and artwork from a privately managed server to the owner's Google Drive account.

What it does

The tool lists files in the connected Google Drive, uploads ZIP backup archives, and checks file metadata and checksums to verify uploads. It may organize backup files in folders selected by the owner.

It is not a public app, does not accept public accounts, and is operated only for the owner's personal backups. The tool requests Google Drive permissions to perform these operations.
